# 价格换算成工作小时数

无外部依赖的 Chrome Manifest V3 插件 MVP。把商品价格换成「≈ X 小时工作」，用时间感受消费成本。界面沿用参考项目的纸色底、印章红和中文卡片样式。

## 安装

1. 打开 Chrome，进入 `chrome://extensions`。
2. 开启右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择当前目录 `/workspace/work-hours-price`（包含 manifest.json）。
4. 打开支持的商品详情页。如果页面在安装或重载插件前已经打开，请刷新页面。
5. 点击扩展图标，在 popup 设置时薪、币种和每日工时，然后点击「换算本页」；也可以点击页面右下角浮动按钮。

默认 USD 时薪 25，每日 8 小时；切换为 CNY 时自动建议时薪 30，可以自行修改。支持 USD、CNY、EUR、GBP 时薪。设置保存在 `chrome.storage.local`。点击「换算本页」也会先保存当前设置。

主价格旁展示「≈ X 小时工作」以及「约 X 小时（Y 个工作日，按每天 N 小时）」。价格区间取低值，结果保留最多两位小数。

## 冲动消费冷静期

在 popup 开启「冲动消费冷静期」，默认 1440 分钟（24 小时），可修改为其他正整数分钟。下一次换算会为商品 URL 建立计时记录，在标注下显示剩余时间和「我已冷静」按钮。记录持久化，刷新、关闭页面后计时仍按实际时间流逝；再次换算同一 URL 不会重启。点击「我已冷静」可提前确认结束，计时结束后也不重新开始。

URL 记录忽略 `#fragment`，保留路径与查询参数；参数不同视为不同商品地址。已建立冷静期的时长不会被后续设置覆盖；关闭开关后，下次换算不显示冷静期。这是提醒工具，不拦截购物或结账。

## 免费次数与离线许可

免费每天 3 次，按本机本地日期重置。一次按钮触发的页面扫描计 1 次，而非每个价格计一次；未找到价格或币种不匹配也计一次。倒计时更新、打开 popup、保存设置、点击「我已冷静」不消耗次数。后台串行处理扣减，避免多页同时操作超额。

超限提示：免费次数已用完，解锁请小红书私信「珊哥爱读书」。

点击 popup 的「输入 license / 解锁」进入 options，输入 `WHP1.` 开头的离线 license。清除许可后恢复当天已有的免费次数状态。开发验证可在本地运行：

```sh
node scripts/gen-license.mjs
```

许可为 `WHP1.` + 种子 `work-hours-price:unlock:v1` 的 SHA-256 十六进制摘要。公开种子与生成脚本仅供 MVP 离线演示，所有用户生成结果相同，不能作为防破解的安全付费系统。本地日期、配额和许可均可被用户修改。

## 支持范围与已知限制

- 候选站点：Amazon 多地区域名、eBay（美国 / 英国）、Target、Walmart、Best Buy；完整域名见 manifest.json。
- **DOM 易变、未真站验收**：仅提供候选选择器，包括 Amazon `.a-price .a-offscreen`、`#corePrice_feature_div`、`#priceblock_ourprice` 等；不能承诺真实站点当前可用。通用 `[itemprop=price]` / meta 兜底只在已授权站点运行。
- **不做汇率换算**：商品和时薪币种必须一致；不匹配时明确提示。`¥` / `￥` 缺省按 CNY，裸 `$` 缺省按 USD；跨地区商店、混合币种、缺失或错误的商品元数据可能导致币种误判。请核对原始价格，无法确认时不要据此决策。
- 无法可靠识别优惠券、税费、运费、分期价、会员价或登录后的个性价格；复杂价格文本可能误取数值。列表页可能取到第一个候选商品；建议仅在商品详情页使用。
- 不自动持续扫描 DOM，不读取 iframe / 封闭 Shadow DOM。SPA 导航或商品变体变化后请重新点击；刷新后需再次换算才显示标注。meta 价格没有可见节点时，在标题旁显示。
- 工时换算是简单除法，没有扣除税、通勤、生活开支；微小价格四舍五入后可能显示 0 小时。
- 权限仅 `storage`、`activeTab`，host_permissions 仅列明的购物站。没有远程请求、统计上传或第三方依赖；浏览购物站仍由网站自身联网。

## 开发和测试

```sh
npm test
```

无需 npm install。使用 Node 内置测试运行器，涵盖价格多格式、工作时间、冷静期、跨日配额与并发、正确 / 错误许可、UMD 浏览器加载、页面消息流和 manifest 引用文件。自动测试使用本地模拟环境，不等于 Chrome 手工验收或真实购物站验收。

目录：`src/lib` 纯逻辑 UMD 模块；`src/content` 选择器和页面标注；`src/background` 本地配额 / 冷静期串行处理；`src/popup` 设置及触发；`src/options` 许可；`src/ui` 公用样式；`icons` 图标；`docs/FEATURE_MAP.md` 功能映射；`scripts/gen-license.mjs` 本地生成许可；`tests/*.test.js` 测试。
